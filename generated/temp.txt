          1. Overview 
          This package reproduces every table and figure in the paper and its appendices. It contains 
          data from surveys and experiments conducted by the authors with undergraduate students 
          through the University of California, Berkeley’s Experimental Social Science Laboratory 
          (Xlab), two extension experiments, and analysis of the American National Election Studies 
          (ANES) survey data. 
          All Stata analysis runs from one master file,  silence_master.do . Figure A.1 is produced 
          separately by a Jupyter notebook. Section 8 maps every exhibit to the code that produces it, 
          the file it writes, and the file the manuscript reads.

          2.2 Data collected by the authors 
          All experimental data were collected by the authors using Qualtrics, with participants 
          recruited from the UC Berkeley Xlab subject pool. 
          On “raw” versus “analysis” data. The raw data were collected via surveys on Qualtrics, so 
          there is no methodological cleaning stage: the data as received from Qualtrics are already           one row per respondent, one column per item. The files in  data/  are close to the Qualtrics 
          exports, there were only two changes that were made between download and analysis of 
          the Qualtrics data: 
            •  De-identification. We removed identifiable information from every dataset that 
               included them: ResponseId, IPAddress, LocationLatitude, LocationLongitude, email, 
               first_name, last_name, login_id, twitter_handle, the Qualtrics panel fields 
               RecipientEmail / RecipientFirstName / RecipientLastName / ExternalReference, 
               and grantor. Every UC Berkeley Xlab (SONA) participant number appearing in the 
               deposited data was mapped through a single global crosswalk to a new ID. 
           •   Renaming the variables. See the codebook for detailed variable names and labels.    
                
          2.3 Third-party data 
          American National Election Studies. data/anes_full.csv  and  anes_full_inperson.csv  
          are extracts aggregated to the year × topic level (448 rows each) from the ANES Time 
          Series Cumulative Data File, covering 1974–2020.

          6. Instructions to replicators 
           1.  Download the package and keep the folder structure intact. 
           2.  Open  silence_master.do  and edit the single path line near the top: 

               global userpath "/path/to/this/package"  

               The other globals ( $data ,  $output ,  $tempfile ,  $code ,  $logs ) derive from it and 
               should not need editing. 
           3.  Install the Stata commands listed in §5.1. 
           4.  Run  silence_master.do . All tables and figures are written to  Output/ ; the full run is 
               logged to  logs/silence_master.log . 

           5.  For Figure A.1, install the Python dependencies numpy ,  numba  and  matplotlib , then 
               open  Code/Figure A1.ipynb  from the  Code/  directory and run all cells. It writes 
               Output/figure_A1.png  plus the four individual panels.  

          6.1 Output displayed rather than saved 
          Every exhibit writes a file to  Output/  except Table D.15, which reports finite-mixture 
          estimates read off the Stata output. The master file captures it in  logs/Table_D15.log , and 
          Code/Table D15.do  documents which part of that output feeds each cell of the table. 
          The other thing that appears in  logs/silence_master.log  rather than in a file: 
           •   The  SUEST  rows of Table 2 — see §8.1. 
           

          7. Runtime

          8.1 Notes on the mapping 
           •   The  SUEST  row in Table 2— chi2(1) statistics 10.54, 10.55, 8.26 with p-values 
               0.0012, 0.0012, 0.0040 — is displayed in the Stata log only and transcribed by hand; 
               Table 2.do  runs the  suest  tests but does not write it to  Output/ . The three values 
               have been verified against the data and are correct as computed.  
           •   Table D.15 is the only exhibit with no file in  Output/ ; see §6.1.            •   Panel merges. Tables 1, 3, C.7, C.8, C.9, D.13, D.14, E.22 and E.23 each combine two 
               Output/  files into a single file in the manuscript. 
           •   Renaming. Some draft filenames differ from the  Output/  filenames they come from 
               (ols_inference_tc_revised.tex  →  reg_inference_tc.tex ).
